# Backend EnterpriseTester

Этот каталог входит в Git и содержит серверную часть, необходимую запускателю:

- `EnterpriseTester.jar` — подготовленный Spring Boot backend (около 77 МБ).
- `backend.json` — SHA-256 этой версии JAR, проверяемый перед запуском.

После полного клонирования репозитория или распаковки готового пакета оба файла уже находятся на месте; отдельная установка web-проекта и импорт не нужны. Проверка SHA-256 не позволяет незаметно использовать другую версию JAR.

Встроенные настройки подключения к БД в подготовленном JAR заменены переменными окружения. Реальные параметры задаются в приватном `config/server.json` и не хранятся в Git.

Проверка без MySQL и Java:

```powershell
dotnet run --project EnterpriseTester.ServerHost -- verify-backend
```

Для обновления backend используйте `import-backend --source путь-к-новому.jar`, затем включите JAR и backend.json вместе в один коммит и пересоберите переносимые пакеты. Не создавайте `backend.json` вручную и не отключайте проверку контрольной суммы.
