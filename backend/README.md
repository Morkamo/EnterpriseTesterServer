# Backend EnterpriseTester

В Git из этого каталога входят документация и небольшой `backend.json`. Исполняемый JAR передаётся отдельно, в готовых пакетах сборки:

- `EnterpriseTester.jar` — подготовленный Spring Boot backend (около 77 МБ).
- `backend.json` — SHA-256 этой версии JAR, проверяемый перед запуском.

Для запуска готового пакета оба файла уже находятся на месте; отдельная установка web-проекта и импорт не нужны. Если запускать клонированные исходники, один раз скопируйте `EnterpriseTester.jar` из соответствующего готового пакета в этот каталог. Одного `git clone` недостаточно для получения Java backend. Проверка SHA-256 не позволяет незаметно использовать другую версию JAR.

Встроенные настройки подключения к БД в подготовленном JAR заменены переменными окружения. Реальные параметры задаются в приватном `config/server.json` и не хранятся в Git.

Проверка без MySQL и Java:

```powershell
dotnet run --project EnterpriseTester.ServerHost -- verify-backend
```

Для обновления backend используйте `import-backend --source путь-к-новому.jar`, затем включите изменившийся `backend.json` в коммит и пересоберите переносимые пакеты. Сам JAR остаётся исключённым из Git. Не создавайте `backend.json` вручную и не отключайте проверку контрольной суммы.
