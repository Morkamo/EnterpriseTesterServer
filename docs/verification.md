# Проверка dedicated-пакета

Проверено 11 октября 2026 года.

- Solution .NET 10 собирается без предупреждений и ошибок. 13 автоматических проверок конфигурации, секретов, защиты схемы и распаковки архивов прошли.
- Windows x64: запуск существующего backend, подключение к MySQL 8.0.46, готовность HTTP, вход администратора, CSRF и экран управления подтверждены.
- Windows BAT проверен отдельно через cmd.exe: формат CRLF, запуск готового self-contained EXE, вывод «ГОТОВО», ответ HTTP и остановка командой ManageServer.bat stop.
- Linux x64: тот же self-contained запускатель и JAR проверены в Ubuntu Jammy контейнере Eclipse Temurin 21. Подключение к существующей MySQL выполнено через отдельный тестовый relay на loopback, без изменения сервера БД. HTTP, вход, CSRF и управление подтверждены.
- Windows и Linux: штатная команда stop завершает собственный backend. Linux получает SIGTERM, подтверждено закрытие Spring/Hikari; Windows завершает процесс после таймаута, если тот не завершился сам. Второй запуск отклоняется; чужие процессы не останавливаются.
- Автоматическая загрузка Java 21.0.12.1 проверена отдельно на Windows и Linux: официальный источник, SHA-256, локальная распаковка и проверка запуска Java.
- Локальный пароль не выводится в консоль, не передаётся в argv Java и не попадает в публичные пакеты. Рабочий конфиг на Windows ограничен ACL, на Linux используется 0600.
- SHA-256 схемы до/после: `36111190B335FD79476B629D60688D9CE15829A54D6A97AAADA9C6C182C97087`. Схема не изменялась, временная тестовая учётная запись удалена.

Пакеты: Windows x64, Linux x64, Linux ARM64. ARM64 собран, но на отдельном ARM64-оборудовании не запускался. Linux проверен в контейнере, не на отдельном физическом сервере. Реальный HTTPS-сертификат и удалённая MySQL с пользовательским CA не предоставлены; соответствующая конфигурация подготовлена, но такое развёртывание требует отдельной проверки. Установка новой MySQL и восстановление базы не выполняются автоматически.

Исходные web-, desktop- и Android-проекты не менялись. Импорт backend создаёт только очищенную копию JAR в dedicated-проекте. Для тестов Docker Desktop был запущен; тестовые контейнеры и relay после проверки убираются. Ваши базы и существующие контейнеры не удаляются.
